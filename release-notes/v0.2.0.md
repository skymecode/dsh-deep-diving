## 蓝色大肥鱼 · 连续动效

- 新增与参考图相符的蓝发鲸鱼娘：思考、奔跑、堆雪人、挥手、写代码、吐泡泡、跳舞、休闲 8 种透明动画。
- 同一轮 Deep diving 内默认每 10 秒换动作，也可固定单个动画或随机轮换皮肤。
- 适配最新 Harness `dsh-v0.1.3-alpha.2`，保留 `0.1.1-rc.2` 等版本的运行时兼容路径；识别新版中文“深度求索中”。
- 修复新旧设置写入接口差异；后台暂停、减少动态效果、禁用/卸载恢复与计时器清理。
- 保留原有四套矢量皮肤；已有配置不会覆盖，升级后请在插件设置中选择“蓝色大肥鱼 · 鲸鱼娘”，开启持续轮换，尺寸设为 48–64px。

## 安装

```sh
dsh plugin --profile web add https://github.com/skymecode/dsh-deep-diving/releases/download/v0.2.0/dsh-deep-dive-skins-0.2.0.tgz
```

替换为你的 profile 名称；升级后重启 `dsh web` 并刷新页面。
