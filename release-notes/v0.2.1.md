## DSH 0.1.5 兼容更新

- SDK / 类型检查基线升级到最新发布版 `dsh-v0.1.5-rc.2`（2026-09-13 核对）。
- 扩展依赖版本范围，接受 `0.1.5` alpha/RC 系列，包括 npm `latest` 对应的 `0.1.5-rc.1`，同时保留 `0.1.1-rc.2` 等旧版兼容范围。
- 核对新版设置槽位、配置接口、浏览器 factory 和求索状态行；沿用已有运行时适配，不更改用户配置或 8 种鲸鱼娘动画。
- 增加 SDK 安装版本、状态行每秒计时更新、切换会话清理的回归测试，防止动画轮换被界面更新打断。

## 验证

28 项单元测试、类型检查、构建、发布 factory / 真实 React 设置卡片、最新 SettingsProvider 注册/卸载及素材检查通过。旧版 `0.1.1-rc.2` Host provider 再次验证通过。

Tabbit 浏览器验证覆盖发布 bundle 的动画轮换、设置保存、减少动态效果及关闭/结束/卸载流程；预览页使用模拟 Host 存储，不等同于完整 DSH 会话 E2E。

## 安装 / 升级

```sh
dsh plugin --profile web add https://github.com/skymecode/dsh-deep-diving/releases/download/v0.2.1/dsh-deep-dive-skins-0.2.1.tgz
```

将 `web` 换成你的 profile 名称，升级后重启 `dsh web` 并刷新页面。现有设置保留。

本次素材未变更：鲸鱼娘素材仍受上游“允许开源使用、禁止商用”限制，详见包内 `assets/whale-maid/NOTICE.md`；插件代码仍采用 Apache-2.0。此版本通过 GitHub Release 附件分发，未发布到 npm。
